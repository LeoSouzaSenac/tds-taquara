Comando para clonar um repositório:
    - git clone link

Comando para adicionar os arquivos para envio:
    - git add .

Comando para adicionar uma mensagem para envio:
    - git commit -m "mensagem"

Comando para criar uma branch/ramificação
    - git branch nome-da-branch

Comando para entrar na branch
    - git checkout nome-da-branch

Comando para enviar tudo para a branch
    - git push origin nome-da-branch

Comando para pegar atualizações:
    - git pull origin nome-da-branch
